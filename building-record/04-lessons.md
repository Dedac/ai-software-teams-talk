# Lessons from building the talk

The build followed the same pattern the talk describes.

- **Start from intent.** The abstract came first; sections followed from it.
- **Add context in rounds.** Sources, then evidence, then outside research,
  rather than one large prompt.
- **Use separate passes.** Flow, messaging, hooks, consolidation, and
  independent review each got their own pass.
- **Plausible isn't proven, here too.** Drafts that read well still had
  errors: who found the bugs, what a prototype allowed, what a study said.
  Each was caught by checking evidence or by the author.
- **The human owns the truth and the framing.** The agent drafted, searched,
  and checked. The author decided what was true, what to drop, how to
  anonymize, and which story mattered.
- **Coordinate agents.** Two agent sessions once started the same update;
  one was stopped and archived before it could push conflicting changes.
- **Keep a record.** Every outline change is a commit, so the process is
  inspectable, which is what made this record possible.
- **Value over volume.** The useful output isn't the number of edits; it's an
  outline the author can stand behind on stage.
