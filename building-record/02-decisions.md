# Decisions

The agent drafted and proposed; the author decided. These are the calls that
shaped the talk.

## Made by the author

- **Agents found every BeamRS problem.** The agent's early draft implied
  people caught some of them. The author corrected it, and the review section
  was rewritten around "agents find, humans decide."
- **Copilot code review is part of the process,** not an afterthought. It
  became the second layer of agent review.
- **A research source was dropped entirely.** It was removed from the
  outline and from future research.
- **Enterprise cases stay anonymous.** No internal project names. QRSPI+ is
  described only as used in a real enterprise.
- **Case A is a different implementation, not an earlier generation.** It
  was renamed "The Relay" so listeners keep it separate from QRSPI+.
- **Section 1 uses a personal story from before AI tools.** The Three-Year
  Rewrite: several teams, more than three years, an app that cost more to run
  than it could earn, scrapped.
- **Value over volume becomes a second theme:** the value of completed work,
  not the amount of work completed.

## Proposed by the agent and accepted

- The thesis: *the bottleneck has moved from writing code to trusting it.*
- The repeated line *"Plausible isn't proven."*
- BeamRS's duplicate interface as the cold open.
- A "this talk was built the same way" segment in section 7.
- Presenting METR's 2025 slowdown result as historical, alongside its 2026
  update.
