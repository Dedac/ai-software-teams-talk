# Building record

A summarized record of how this talk was built in one human–agent session.
It doubles as the short case study in section 7 of the outline, "This talk
was built the same way."

| File | What it covers |
|---|---|
| [01-timeline.md](01-timeline.md) | Each request in the session, what the agent did, and the result |
| [02-decisions.md](02-decisions.md) | Editorial and framing decisions, and who made them |
| [03-verification.md](03-verification.md) | How claims were checked against evidence, and what changed as a result |
| [04-lessons.md](04-lessons.md) | What the build process shows about working with agents |

Names of internal projects, companies, and some dropped sources are
deliberately left out, matching the outline's anonymization rules.
